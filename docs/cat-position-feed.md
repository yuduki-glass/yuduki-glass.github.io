# 観測ページの位置フィード

公開サイトの `/cat/positions.json` に、観測判定を通った現在の個体だけを載せる。非公開のチェックポイント、認証情報、内部ログは公開フィードに含めない。位置の計算と可視判定は配信元で完了させる。

| 項目 | 形式 |
| --- | --- |
| `version` | 数値の `1` |
| `observedAt` | 位置を確定した時刻。タイムゾーン付きISO 8601 |
| `validUntil` | 情報を表示できる期限。確定から65分以内 |
| `cats` | 最大3件の配列。観測できる猫が0匹の場合は空配列 |
| 猫の `id` | `"01"` 三毛、`"02"` 黒、`"03"` 茶トラ |
| 猫の `visible` | 描画対象かを示す真偽値 |
| 猫の `x`、`y` | 背景全体に対する足元の座標。左上を原点とする0〜1の数値 |
| 猫の `facing` | 左向きは `-1`、右向きは `1` |
| 猫の `layer` | `street`、`wall`、`behindWall` |
| 猫の `action` | `still`、`walk`、`sit`、`sleep`、`sniff`、`crawl`、`groom` |

ブラウザは表示中に1分間隔で更新する。期限切れ、取得失敗、画角外、不可視の個体は描画しない。単発の位置だけを受け取るため、`walk` の記録は足元の位置で立ち姿として表示する。

本番の配信元には、区域を背景上の代表点に対応させるか、確定した詳細座標を出力する処理が必要。区域を使う場合、特定の車の下・塀の上といった区域内の詳細位置は推定しない。このリポジトリは、GAS側での可視判定やデータ公開を自動で行わない。
