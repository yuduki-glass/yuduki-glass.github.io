今朝は「昨日から今朝にかけて、実際に使い方が変わるもの」を優先して調べた。今回は7件。特に実用度が高いのは、ChatGPTの新しい対話画面、会議メモ機能、GeminiのSkills、そしてCodex/Claude Codeの利用量を分解して見る方法。

## 1. ChatGPTが「文章を返す箱」から、その場で操作できる道具を作る方向へ

**情報の確度：** 確認済み

**難易度：** すぐ使える

### 何が話題？

OpenAIは10月7日、ChatGPTへGPT-6とIntelligent UIを導入した。質問内容に応じて、文章だけでなく比較表、図、操作できるグラフ、計算機などを会話内に自動生成する。Plus、Pro、Business、Enterpriseでは10月7日から、FreeとGoは10月8日から順次展開。

### つまり何ができる？

「説明して」で文章を読むだけでなく、「この条件を動かしたら結果がどう変わる？」をその場で触って確認できる。家計、料金比較、数値シミュレーション、仕組みの理解などで効く。

### こんな人に役立つ

数字の比較、Excelの式の理解、費用計算、技術説明をChatGPTへ頼む人。

### 具体的な使用例

「月5000円を年利3％で積み立てた場合、期間と金額を変更できる計算機を作って」と頼み、条件を触りながら比較する。

### 試し方

1. ChatGPTを開く
2. 「文章で説明するだけでなく、操作できる比較表や計算機にして」と頼む
3. 数値を変更する
4. 自分の用途で本当に便利か確認する

### 料金・制限・罠

段階展開なので、同じプランでもまだ表示されない場合がある。見た目が立派でも計算内容が正しい保証にはならない。重要な数字は元データと式を確認する。

### 検証するとどこまで本当？

機能、対象プラン、展開日はOpenAI公式リリースノートで確認済み。

**情報源：** OpenAI ChatGPT Release Notes（2026年10月7日）

> **結月硝子一言：** これは地味に大きい。AIが「答えを書く」から「その質問専用の小さな道具を作る」へ寄ってきた。

## 2. 会議を録って要約するだけでなく、そのままメールや次の仕事までつなげられる

**情報の確度：** 確認済み

**難易度：** すぐ使える

### 何が話題？

ChatGPTのmacOS版にMeetingsプラグインが登場した。オンライン会議や対面会話を記録し、文字起こし、個人向け要約、次にやることをChatGPT Spaceへ保存する。さらに、その内容からメール作成や計画更新などの作業へ進められる。現在はProとBusiness向けベータで、Windows対応は今後予定。

### つまり何ができる？

「会議→文字起こし→AIへ貼る→要約→Todo作成→メールを書く」という人間のコピペ工程をかなり削れる。

### こんな人に役立つ

研修、打ち合わせ、引き継ぎ、議事録を扱う人。音声をAIで整理する運用をしている人には特に分かりやすい進化。

### 具体的な使用例

研修終了後に「今日決まったこと」「自分が覚える用語」「明日確認すること」を自動整理し、そのまま復習資料へする。

### 試し方

Mac利用者なら、

1. ChatGPTデスクトップ版を開く
2. PluginsからMeetingsを導入
3. マイクとシステム音声を許可
4. 参加者の同意を得てTake notesを開始
5. 終了後に要約と行動項目を確認する

### 料金・制限・罠

現時点ではMacのPro/Business向け。録音前に参加者の同意が必要。OpenAI公式も、文字起こしや要約には誤りがあり得るので重要事項は確認するよう明記している。音声は処理後に削除されるが、処理中はOpenAIへ送信される。

### 検証するとどこまで本当？

OpenAI公式ヘルプで手順、対象プラン、音声処理、Windows対応予定まで確認済み。

**情報源：** OpenAI「The Meetings plugin in ChatGPT」

> **結月硝子一言：** Windows対応が来たら、Win+Hで文字起こしして後からAIへ渡す方式と比較する価値がある。Meetingsは「記録後の作業までつながる」のが本体。

## 3. Geminiでも「毎回同じ長文プロンプト」を保存して呼び出せるSkillsが本格展開

**情報の確度：** 確認済み

**難易度：** すぐ使える

### 何が話題？

GoogleはGeminiのGemsをSkillsへ置き換え始めている。よく使う指示を一度保存し、通常のGemini会話で「/スキル名」と入力して呼び出せる。複数Skillsの組み合わせや参照ファイル追加にも対応する。

### つまり何ができる？

毎回「この形式で議事録を整理して」「この観点でExcelを確認して」と長文を書く必要が減る。

### こんな人に役立つ

Geminiへ定型作業を何度も頼む人。AIへ毎回同じ説明をしている人。

### 具体的な使用例

「新人研修整理」というSkillを作り、音声文字起こしを渡すだけで、用語、要点、質問事項、翌日の復習項目へ整理する。

### 試し方

1. GeminiでSkill作成画面を開く
2. よく使う指示を登録
3. 名前を付ける
4. 通常会話で「/名前」を入力して呼び出す
5. 同じ資料で通常プロンプトと結果を比較する

### 料金・制限・罠

個人向けGeminiでは世界展開が始まっているが、Workspaceは今後数週間かけて展開。既存Gemsは移行予定。組織アカウントでは管理者設定にも左右される。

### 検証するとどこまで本当？

Google公式ブログで確認済み。

**情報源：** Google公式「Let skills in Gemini tackle your most repetitive tasks」（2026年9月30日）

> **結月硝子一言：** 昨日紹介した「よく使う作業手順を保存する」が、Geminiではもう製品機能として正面から来ている。プロンプト職人より手順書職人の方が長生きしそう。

## 4. CodexやClaude Codeが「何に利用量を食っているか」を分解して見るツールが実用段階

**情報の確度：** かなり確からしい

**難易度：** 技術者向け

### 何が話題？

GitHubで公開されているcost-xrayは、Claude CodeやCodexが実際にAIへ送る情報をローカルで解析し、システム指示、MCP、ツール結果、キャッシュなど「何が何トークン・何ドル使っているか」を分解表示する。単なる総額表示ではなく、使っていないMCPが毎回どれだけ情報量を食っているかまで確認できる。

### つまり何ができる？

「Codexの利用量が多い」から一歩進んで、「このMCPを入れたせいで毎回大量の説明文をAIへ送っている」のような原因を探せる。

### こんな人に役立つ

CodexやClaude Codeを日常的に使い、利用量制限やAPI料金を減らしたい人。

### 具体的な使用例

MCPを5個設定しているが、実際には1個しか使っていない場合、残り4個の機能説明が毎回AIへ渡されていないか調べ、不要なものを外す。

### 試し方

現状はmacOS/Linux向け。会社PCへいきなり入れず、まずGitHubのREADMEとSECURITY.mdを読む。検証環境で導入し、数セッション使って「利用していないのに情報量を消費しているMCP」がないか見る。

### 料金・制限・罠

MITライセンスのOSS。Codexでは通信内容を解析するためローカルCAを使う仕組みがある。作者はOS全体には登録せずCodexコマンドだけに限定すると説明しているが、会社PCで勝手に通信中継ソフトを入れるのはやめた方がいい。

### 検証するとどこまで本当？

機能と実装はGitHubで確認できる。ただし「これを入れれば何％節約できる」という保証はない。節約額は自分の構成次第。

**情報源：** GitHub tigerless-labs/cost-xray

> **結月硝子一言：** 利用量節約ではかなり面白い。「節約テクニック」を集める前に、何が金を食っているか測る。ようやく話が会計になった。

## 5. Claude Codeが、実際の作業から自動で「自分専用Skills」を学習する実験が急伸

**情報の確度：** かなり確からしい

**難易度：** 技術者向け

### 何が話題？

AutoHarnessというClaude Code用OSSが注目を集めている。通常の作業セッションから再利用できそうな手順を抽出し、Skillとして保存、似たSkillを統合し、使われなくなったものを整理する。10月6日にも更新され、GitHubでは約9千スター規模まで伸びている。

### つまり何ができる？

自分で毎回「これは覚えておこう」と手順書を作らなくても、AIが実作業から再利用ルールを作る方向。

### こんな人に役立つ

同じコードベースをClaude Codeで長期間触る人。毎回同じ注意点を説明している人。

### 具体的な使用例

「このシステムでは修正後に必ずこのテストを行う」「このファイルは直接変更しない」といった実務上の癖を、繰り返し作業からSkillへ昇格させる。

### 試し方

Python 3.11以上が必要。現時点ではまずREADMEを読んで仕組みを理解するのがおすすめ。試すなら検証用プロジェクトで `/learn` を使い、生成された `.claude/skills/` の内容を人間が確認する。

### 料金・制限・罠

OSS自体は無料。ただしSkill生成にもAI利用量を使う。さらに、間違った作業を繰り返せば間違った癖を学習する可能性がある。「自動学習」は「自動で賢くなる」の同義語ではない。

### 検証するとどこまで本当？

仕組みとコードは公開済み。一方、READMEにある性能向上値は開発側の評価なので、一般環境で同じ効果が出る保証はない。

**情報源：** GitHub tigerless-labs/autoharness

> **結月硝子一言：** Skillsの次は「Skillsを書く作業すらAIへ渡す」。方向としては自然。ただし悪癖まで立派な社内標準に昇格させるのは人類が昔から得意なので、承認工程は残した方がいい。

## 6. AIにコードを直させる前に「安全監査だけさせる」ためのSkillも出てきた

**情報の確度：** 確認済み

**難易度：** 技術者向け

### 何が話題？

CloudflareはAIコーディングエージェント向けのSecurity Audit SkillをGitHubで公開している。コード、API、サービスなどを調べ、実際の信頼境界を破る脆弱性を探し、根拠、再現方法、優先度、最小限の修正案を整理する設計になっている。

### つまり何ができる？

AIへいきなり「全部直して」と権限を渡す前に、「まず問題を探して報告だけして」という監査工程を独立させやすい。

### こんな人に役立つ

Codex、Claude Codeなどへコード変更を任せている開発者。

### 具体的な使用例

AIが作ったWebアプリを別セッションのAIに監査させ、SQLインジェクション、認証漏れ、秘密情報の扱いなどを確認してから修正へ進む。

### 試し方

1. Skillの内容を読む
2. 自分のAI環境で読み込ませる
3. 最初は「変更禁止、監査と報告だけ」と明示
4. 指摘された箇所を人間が確認
5. 確認できたものだけ別工程で修正する

### 料金・制限・罠

AIによるセキュリティ監査は人間の専門監査の代用品ではない。見逃しも誤検出もある。逆に、修正権限まで一気に与えないことで被害範囲はかなり狭められる。

### 検証するとどこまで本当？

Skill本体と監査手順はCloudflareのGitHubで確認できる。検出精度について万能という根拠はない。

**情報源：** GitHub cloudflare/security-audit-skill

> **結月硝子一言：** 「作るAI」と「検査するAI」を分けるのは合理的。同じAIに作文と採点を同時にやらせると、自分に甘い教師が誕生する。

## 7. Claude Codeのクラウド実行を試せる大型クレジット、対象者は今日の午後まで間に合う可能性あり

**情報の確度：** かなり確からしい。公式一次情報を今回の検索では直接確認できず

**難易度：** 少し設定が必要

### 何が話題？

複数の情報源で、既存Claude Pro利用者に100ドル、Max利用者に250ドルのClaude Code Cloud Sessions用クレジットが案内されている。申請期限は米国太平洋時間10月7日23:59とされており、日本時間では10月8日15:59ごろに相当する。

### つまり何ができる？

対象者なら、PCを閉じてもクラウド側で続くClaude Code作業をまとまった無料クレジットで試せる可能性がある。

### こんな人に役立つ

すでにClaude Pro/Maxを契約し、Claude CodeとGitHubを使っている人。

### 具体的な使用例

時間のかかるテスト修正や依存ライブラリ更新をクラウドセッションへ投げ、PCを別作業へ戻す。

### 試し方

Claude Code利用者は `/claim-credit` が利用可能か確認する。表示された場合は、金額・有効期限・対象用途を画面上で必ず確認してから受け取る。

### 料金・制限・罠

ここは注意。今回の検索ではAnthropic公式ページを直接拾えず、二次情報同士の一致までしか確認できなかった。そのため「かなり確からしい」止まり。クレジット欲しさに新規契約するほどの確度ではない。既存契約者が自分の画面で確認する価値がある、という位置づけ。

### 検証するとどこまで本当？

複数の独立した二次情報で金額、期限、利用方法が一致しているが、公式一次情報を今回確認できていない。

**情報源：** Claude Code Cloud Sessionsクレジットに関する複数の利用案内

> **結月硝子一言：** 無料枠ネタは「本当に無料か」を疑ってちょうどいい。既存契約者なら確認する価値あり。未契約者が250ドルという数字に釣られて契約するのは順序が逆。

## 今日の観測

今日かなりはっきりしているのは、AI活用の主戦場が「もっと上手なプロンプトを書く」から、その前後へ広がっていること。

ChatGPTは回答そのものを操作可能な道具に変え、Meetingsは会議から次の作業までつなぐ。Geminiは繰り返す指示をSkillsへ格上げし、Claude Code周辺では実作業からSkillsを自動生成するところまで来た。一方、cost-xrayのように「AIが裏で何を読んで、何に金を使っているのか」を測る道具も出ている。

つまり次の改善ポイントは、プロンプトの言い回しより「入力→AI→確認→次の作業」という工程設計。AIが多少賢くなるより、コピペ3回がゼロになる方が日常業務では普通に強い。

## 今日ひとつだけ試すなら

「いつもAIに頼んでいる作業を、操作できる道具として作らせる」を試す。

追加料金なし。ChatGPTで5〜10分。

1. ChatGPTを開く
2. 普段、数字を変えながら何度も質問している作業を1つ選ぶ。たとえば、料金比較、収納量、作業時間、予算配分、積立計算など。
3. 次のように入力する。

> この計算を文章で答えるだけではなく、条件を変更して何度も比較できる操作式の表または計算機にしてください。変更できる項目と、結果として確認したい項目を分けてください。

4. 数値を何度か変更し、会話で再質問するより使いやすいか確認する。

GPT-6のIntelligent UIが有効なら、ここでインタラクティブな表示が出る可能性がある。まだ展開されていなくても、どういう道具が欲しいかをAIに設計させる練習にはなる。

今日の本命はここ。AIを「質問すると返事をする人」から「その仕事専用の小道具をその場で作る人」へ切り替える。毎回同じ計算を会話でやり直していたなら、かなり露骨に手数が減る。
