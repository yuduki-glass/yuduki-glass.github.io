## 1. 【全ユーザー】Gemini、PDF・スライド・表計算をチャット内で直接作成・編集。PPTX/PDF出力にも対応

**情報の確度：確認済み**

### 何が話題？

Googleは10月29日、Geminiアプリ内で文書、PDF、プレゼン、表計算、Markdown、テキスト、コードを生成・プレビュー・編集できる機能を公開した。Geminiアプリが提供されている全言語・全ユーザーが対象。PDFはWebとモバイル、その他の形式は現時点ではWeb中心。

### つまり何ができる？

Geminiに資料を作らせ、別アプリへ移る前にその場で文章や構成を直接直せる。スライドはGoogle Slidesへ送るだけでなくPPTX/PDFとして出力でき、表はGoogle Sheetsへ送れる。

### こんな人に役立つ

PowerPoint、PDF、表計算、議事録を日常的に扱う会社員。

### 具体例

「この議事録から役員向け5枚の進捗報告資料を作成」→プレビュー→3枚目だけ選択して「半分の文章量に」→PPTX出力、までGemini内で進める。

**難易度：すぐ使える。**

### 試し方

①Gemini Webを開く ②簡単な資料作成を頼む ③プレビューで一部を直接編集 ④PPTX/PDFへ出して崩れを確認する。

### 料金・制限・罠

今回の機能自体はGeminiアプリが利用可能な全ユーザー・全言語が対象。ただしファイル形式によってWeb限定。会社資料を個人アカウントへ入れてよいかは組織規程を別途確認する。

### 検証

Google公式ブログとWorkspace Updatesで確認済み。

**情報源：Google公式「Edit and preview documents directly in Gemini」**

> 結月硝子一言：これは地味に大きい。「AIで文章を作る→PowerPointへコピペ」の継ぎ目をGoogleが削り始めた。

## 2. 【Pro/Business対象】ChatGPT契約者にOpenAI APIクレジット。月最大500ドル、ただしPlusは対象外

**情報の確度：確認済み**

### 何が話題？

OpenAIは10月28日、対象のChatGPT ProとBusiness契約者がOpenAI API用クレジットを受け取れる制度を開始した。Proは契約階層に応じ月100/200/500ドル、BusinessはStandard席20ドル、Premium席100ドル相当を合算し、月500ドルが上限。

### つまり何ができる？

ChatGPT画面ではなく、Python、自作アプリ、社内ツールからOpenAI APIを呼ぶ実験を追加料金なしで始めやすい。

### こんな人に役立つ

PythonでCSV処理やメール分類、社内ツールを作りたいPro/Business利用者。

### 具体例

Excelから出した500行のCSVをPythonで読み、問い合わせ分類・表記統一・要約をAPIで一括処理する。

**難易度：少し設定が必要。**

### 試し方

①ChatGPTのBillingを確認 ②API credits benefitがあれば所有するAPI Organizationへ紐付け ③API Platformで残高確認 ④小さなAPI処理から試す。

### 料金・制限・罠

Plus、無料トライアル等は対象外。対象契約が7日以上有効である必要があり、初回付与は請求期間の残り日数に応じて按分される。ChatGPTやサインイン版Codexの利用上限が増える制度ではない。

### 検証

OpenAI API ChangelogとHelp Centerで確認済み。

**情報源：OpenAI公式 API Changelog / API credits benefit**

> 結月硝子一言：Plus民には降ってこない。料金表というものは、人間の希望を細かい文字で調整するために存在している。

## 3. 【一般提供】GitHub Copilot Fusion、仕事ごとに複数AIを自動選択。モデル選びとコスト調整を自動化

**情報の確度：確認済み**

### 何が話題？

GitHub Copilot Fusionが一般提供になった。ユーザーが毎回モデルを固定せず、Copilot側が依頼内容に応じてモデルを選択・組み合わせる。Standard / High / Maxの努力量を選べる。

### つまり何ができる？

簡単な修正に高価なモデルを使い、難問に軽量モデルを使うような無駄を減らしやすい。GitHubはFusion Maxについて、公開ベンチマーク上で高い性能を保ちつつ平均APIコストとトークン量を約半分に抑えたとしている。ただしこれはGitHub側のベンチマーク結果。

### こんな人に役立つ

Copilotで複数モデルを使い分けている開発者。

### 具体例

軽いコード説明、小修正、難しいデバッグを全部Fusionへ渡し、固定モデル運用と品質・時間・消費量を比較する。

**難易度：すぐ使える。**

### 試し方

①Copilotのモデル選択を開く ②Fusion Standardを選択 ③普段の小タスクを実行 ④固定モデルと結果を比較する。

### 料金・制限・罠

自動選択だから必ず最安になるわけではない。複数モデルを使う場合もあるので、実際の消費量を見る。

### 検証

GitHub公式Changelogで一般提供を確認済み。

**情報源：GitHub公式「Route and orchestrate models with GitHub Copilot Fusion」**

> 結月硝子一言：モデル比較表を毎朝読む仕事までAIに奪われ始めた。そこは喜んで渡していい仕事だと思う。

### つまり何ができる？

### こんな人に役立つ

### 具体例

**難易度：少し設定。**

### 試し方

①CopilotのCustomize/Connectorsを開く ②一つだけサービス接続 ③読み取り作業を依頼 ④権限範囲を確認する。

### 料金・制限・罠

### 検証

GitHub公式で26サービスと接続方式を確認済み。

**情報源：GitHub公式「Connect your tools to Copilot without all the setup」**

> 結月硝子一言：MCPがようやく「設定できる人だけの玩具」から普通の接続ボタンへ降りてきた。

### 何が話題？

### つまり何ができる？

個人の「便利なAI設定」ではなく、チーム共通の業務フローとしてAIを管理できる。

### こんな人に役立つ

GitHubを業務で使う開発チーム、情シス、社内ツール担当。

### 具体例

Issue作成→AIが分類→必要なら調査→PR作成→人間の反応を一週間集計→改善案を提案、という循環を作る。

**難易度：少し設定〜技術者向け。**

### 試し方

①小さなAutomationを作る ②Sharedを選択 ③Per-run上限を低く設定 ④一週間の結果を見て改善提案を確認する。

### 料金・制限・罠

Pro、Pro+、Max、Business、Enterprise向けに展開。自己改善は勝手に適用されず、人間が承認・拒否できる。これは面倒ではなく必要なブレーキ。

### 検証

GitHub公式のShared Automations、Cost Controls、Self-improvement各発表で確認済み。

**情報源：GitHub公式 Copilot Automations Changelog群**

> 結月硝子一言：作った本人しか分からない自動化が退職と同時に遺跡になる問題へ、ようやく製品側が対処し始めた。

## 7. 【提供中】ChatGPTからServiceNowの障害・変更情報を調査し、そのままレコード更新できるMCP連携

**情報の確度：確認済み**

### 何が話題？

OpenAIとServiceNowは10月28日に提携拡大を発表。ServiceNow MCP pluginはOpenAI marketplaceですでに利用可能で、ChatGPTから類似インシデント検索、変更リスク確認、ServiceNowレコード更新などを行う構成が示された。

### つまり何ができる？

情シス担当がChatGPTとServiceNowを往復せず、「この障害と似た過去事例を探して→変更リスクを見て→担当を割り当てる」と会話内で進める方向になる。

### こんな人に役立つ

ServiceNowを使う情シス、ITサービス管理、セキュリティ部門。

### 具体例

監視アラート→最近の変更→影響サービスをChatGPTで横断確認し、適切な担当チームを決めてServiceNow側を更新する。

**難易度：企業向け。管理者設定が必要。**

### 試し方

①OpenAI marketplaceでServiceNow MCP pluginを確認 ②検証環境へ接続 ③読み取り権限から始める ④既存のServiceNow権限とAI操作範囲が一致するか確認する。

### 料金・制限・罠

企業契約・権限設定に依存。将来予定の機能も多く、CodexのAI Workflow Factory統合は2027年予定。今日使えるMCP pluginと将来機能を混同しない。

### 検証

OpenAI公式発表で、MCP pluginが現在利用可能であることを確認済み。

**情報源：OpenAI公式「OpenAI and ServiceNow expand partnership across enterprise workflows」**

> 結月硝子一言：AI導入の本丸は「チャットを導入しました」ではなく、既存の業務台帳を読んで更新できるところ。ここからが面倒で、ここからが本当に便利。

## 8. 【日本提供開始・早期アクセス】Alexa+が日本上陸。Prime会員は正式提供後も追加料金なし

**情報の確度：確認済み**

### 何が話題？

Amazonは10月29日、日本で生成AI版Alexa「Alexa+」の早期アクセスを開始した。日本全国で順次展開され、早期アクセス中は無料。終了後は非Prime会員が月額3,000円、Prime会員は追加料金なし。

### つまり何ができる？

従来の決め打ち命令だけでなく、自然な会話からスマートホーム、買い物、音楽、予定、食事計画などを扱える。レストラン予約やフードデリバリーなどは日本では今後対応予定。

### こんな人に役立つ

Echo、Fire TV、Alexa対応家電を使っている家庭。特にPrime会員。

### 具体例

「寝る準備したい」のような曖昧な言い方から、照明など複数の家庭操作につなげる。好みを覚えさせ、継続会話もできる。

**難易度：すぐ使える。ただし早期アクセス対象になる必要あり。**

### 試し方

①AmazonのAlexa+ページでEarly Accessを申し込む ②対象端末を確認 ③利用可能になったら従来の単発命令ではなく自然文で話す ④実行前確認や誤認識を観察する。

### 料金・制限・罠

早期アクセス無料。正式提供後はPrime会員追加料金なし、非Primeは月3,000円。すべての既存Echoが対応するわけではない。また予約・デリバリー等は「今後」で、今日全部使えるわけではない。

### 検証

Amazon Japan公式で日本開始日、Early Access、料金を確認済み。

**情報源：Amazon Japan公式「Amazon、生成AI搭載の次世代パーソナルアシスタント、Alexa+を国内で提供開始」**

> 結月硝子一言：今日の生活枠トップ。こういう「昨日まで家でできなかったことが今日からできる」をAI速報で落とさないために7:3へ直した。

## 9. 【日本で利用可能】LINEに食事写真を送るだけで、AIがカロリー・栄養を記録する「食事管理」開始

**情報の確度：確認済み**

### 何が話題？

LINEヤフーは10月28日、Agent iに「食事管理」エージェントを追加。写真や簡単なテキストを送るとカロリー・栄養素を分析し、日次・週次の振り返りや目的に応じたアドバイスを返す。LINE公式アカウントからも記録できる。

### つまり何ができる？

食事管理アプリへ料理名を毎回細かく入力する手間を減らせる。「朝ごはんは昨日と同じ」のような入力も可能。

### こんな人に役立つ

食生活をざっくり記録したい人、入力が面倒で食事記録が続かなかった人。

### 具体例

昼食の写真を送る→推定カロリーと栄養を記録→夜に不足傾向を見る→週末に一週間を振り返る。

**難易度：すぐ使える。**

### 試し方

①LINEのAgent iを開く ②食事管理を選択 ③写真1枚と6つの初期質問で設定 ④次の食事から写真だけ送ってみる。

### 料金・制限・罠

画像からの栄養値は推定であり実測ではない。油、調味料、重量、隠れた材料までは写真だけで正確に判断できないため、厳密な医療・栄養管理の数値として扱わない。

### 検証

LINEヤフー公式で提供開始と利用手順を確認済み。

**情報源：LINEヤフー公式「LINEに食事写真を送るだけでAIがカロリーや栄養素を分析」**

> 結月硝子一言：AIの価値が「栄養について質問できます」ではなく「写真を送れば記録作業そのものが減る」になっている。こっちの方が生活では強い。

## 10. 【日本で順次提供】Yahoo!ショッピング、クーポン・ポイント・送料込みでAIが商品を比較する「AIベスト提案」開始

**情報の確度：確認済み**

### 何が話題？

Yahoo!ショッピングは10月28日、「AIおまかせ比較」を「AIベスト提案」へ刷新し順次提供を開始。「価格」「お届け」「評価」「ベスト」で商品候補をランキングする。

### つまり何ができる？

単純な表示価格ではなく、自分が利用可能なクーポン、獲得ポイント、送料などを含めた比較ができる。配送速度や評価重視にも切り替えられる。

### こんな人に役立つ

Yahoo!ショッピング利用者。複数ストアで同一・類似商品を比較する人。

### 具体例

家電を探す→条件を指定→実質価格重視と配送重視を切り替える→最後だけ商品ページで価格とポイントを確認して購入する。

**難易度：すぐ使える。**

### 試し方

①Yahoo!ショッピングの商品詳細またはお気に入りを開く ②AIベスト提案が表示されているか確認 ③条件を指定 ④価格順とベスト順の差を見る。

### 料金・制限・罠

PC/Web、iOS、Androidへ順次提供なので、まだ表示されないユーザーもいる。生成AIの出力は保証されないため、購入直前の金額・ポイント・配送条件は商品ページで再確認する。

### 検証

LINEヤフー公式で提供開始、比較項目、対応環境を確認済み。

**情報源：LINEヤフー公式「Yahoo!ショッピング、AIベスト提案を提供開始」**

> 結月硝子一言：AIに「最高の商品を選んで」と丸投げするより、面倒な送料・ポイント計算を任せる方が堅実。人類とAI、ようやく適切な分業が見えてきた。

## 今日の観測

今日の大きな流れは「AIそのものを使う」から「今使っている道具の中へAIが入り、作業を最後まで進める」への移行。

業務側ではGeminiがファイル編集画面へ入り、CopilotがSlackやSentryを読み、Windows/macOSアプリを操作し、ServiceNowではChatGPTから業務レコードまで更新できる。つまりAIチャットと業務システムの境界が薄くなっている。
